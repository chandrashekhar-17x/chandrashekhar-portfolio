# CAD Playground (public demo)

**Status: planned.** An open-source, public mini version of my CAD work.

## Why

My CAD editor is employer work, so its code and screenshots can't be shown. The playground proves the same skills on public sample DXF files, with no employer code.

## Planned features

- pan/zoom, hover and select
- R-tree overlay toggle (see the spatial index at work)
- move, copy, delete, with undo/redo
- fit-to-screen and DXF export
- a red/green diff between two sample versions

## Tech

Three.js · TypeScript · R-tree (rbush) · DXF parsing
