# Website & Knowledge-Base Ingestion

> Employer project: client names, internal names, screenshots and code are omitted. Visuals are recreated illustrations.

## What it does

Modules to ingest websites and files into a knowledge base.

## Approach

- URL and file upload, including bulk upload
- URL restrictions and permission-based access (RBAC)
- PDF and HTML rendering
- bounding-box visualization and accessibility-tree tooling

## Tech

Angular · RBAC · bulk upload · PDF/HTML rendering · bounding boxes · accessibility tree
